# InfoSphere

InfoSphere is an interactive market-research website focused on the global economy and trading conditions from **2000–2026**.

## Features
- Category filters (Macro, Equities, FX, Rates, Commodities, Crypto, Policy)
- Live search bar with suggestion chips
- Macro event timeline with trading-focused summaries
- Auto-calculated statistics (growth, inflation, returns, volatility)
- Built-in canvas charts for GDP growth, inflation, equities, and commodities
- Evidence links to IMF, World Bank, BLS, FRED, and S&P data hubs

## Run locally
```bash
python3 -m http.server 8000
```
Then open <http://localhost:8000>.
